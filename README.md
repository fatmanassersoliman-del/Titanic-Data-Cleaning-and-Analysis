# Titanic Data Cleaning and Analysis Using Excel

## Project Overview

This project analyzes the Titanic dataset using Microsoft Excel. The goal is to clean the data, create useful features, and identify patterns related to passenger survival.

## Tools Used

- Microsoft Excel
- Excel Formulas
- PivotTables
- PivotCharts
- Data Cleaning Techniques

## Data Cleaning Steps

- Checked missing values in the dataset.
- Replaced missing Age values using the median age.
- Filled missing Embarked values using the most frequent category.
- Created a Has_Cabin column to identify whether cabin information was available.
- Cleaned passenger names.
- Created Family_Size.
- Created Age_Group.
- Documented the cleaning process in Cleaning_Log.

## Analysis Performed

- Survival rate by sex.
- Survival rate by passenger class.
- Survival rate by age group.
- Comparison between survived and non-survived passengers.

## Key Insights

- Female passengers had a higher survival rate than male passengers.
- Passengers in higher classes generally had better survival outcomes.
- Teenagers had the highest survival rate in the age-group analysis.
- Seniors had the lowest survival rate among the defined age groups.

## Project Files

- `Titanic_Data_Cleaning_and_Analysis.xlsx`: The Excel workbook containing raw data, cleaned data, cleaning log, PivotTables, and charts.

## Conclusion

This project demonstrates a complete data-cleaning and exploratory-analysis workflow using Excel.
